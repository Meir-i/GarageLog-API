# GarageLog API

RESTful API server for vehicle maintenance and fault logging.
Built with Node.js, Express, SQLite, and Sequelize ORM.

## Setup Instructions

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Rename `.env.example` to `.env` and configure your secret keys.
4. Run `node server.js` to start the server.

The server runs on http://localhost:3000
